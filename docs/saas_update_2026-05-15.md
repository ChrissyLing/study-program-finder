# SaaS 化与横滚改造说明（2026-05-15）

## 1. 本次功能清单

### 1.1 站点去个人绑定与文案通用化
- 站点标题、`meta description`、首页说明改为面向所有申请者的中性工具站表述。
- 移除首页中带有个人用途倾向的描述，统一改为“申请者档案 / 项目对比 / 背景评估”等中性措辞。
- README 同步改为通用版本，补充本地存储说明。

### 1.2 通用化匹配流程
- 保留原有 Reach / Match / Safety 与硬门槛评估逻辑。
- 改为：
  1. 用户先填写档案；
  2. 可手动保存到 localStorage；
  3. 必须手动点击“保存并评估”后，页面才显示个人匹配结果。
- 页面刷新后：
  - 会自动载入档案；
  - **不会自动恢复评估结果**。
- 未评估前，列表只展示项目本体信息，不显示个人匹配 badge 与解释。

### 1.3 轻量 SaaS（全部 localStorage）
- 个人档案：
  - 保存档案
  - 自动载入档案
  - 清空档案
- 项目收藏：
  - 表格 / 卡片 / 详情页均可收藏
  - 侧栏预览收藏列表
  - 收藏弹窗查看完整列表
  - 支持“仅看收藏”筛选
- 项目对比：
  - 最多保留 4 个项目
  - 表格、卡片、详情页均可加入对比
  - 对比弹窗同屏并列展示关键字段
- 明示本地存储限制：
  - 数据只存在当前浏览器
  - 清缓存 / 换设备 / 无痕模式会丢失

### 1.4 横向滚动与 sticky 首列改造
- 列表页表格启用 sticky 首列，固定“项目名（含院校）”。
- 首列加入右侧阴影和边框，增强分隔感。
- 列表、申请轮次表、对比表统一加入横滚提示与左右渐变阴影。
- 移动端保留横向滚动能力，并启用 `-webkit-overflow-scrolling: touch`。
- 详情页中的 Deadline 区块改为更适合横向核对的表格结构。

## 4. 已知限制
- 仍为纯静态站点：没有账号系统、没有跨设备同步、没有服务端备份。
- 对比、收藏、档案都依赖浏览器 localStorage；清缓存后会丢失。
- 匹配逻辑仍是规则型前端估计，不是录取预测模型。
- 某些项目字段原始数据缺失时，页面会直接显示“数据缺失”，不会自动补齐。
- 详情弹窗中的对比与来源查看仍以弹窗方式呈现，未单独拆出独立路由页面。
