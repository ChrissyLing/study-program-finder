# 学费一键转 RMB 变更说明（2026-05-15）

## 本次新增能力
- 新增**全局币种切换开关**：页面搜索栏右侧支持 `原币种` / `¥ RMB` 一键切换，全站学费同步更新。
- 新增**局部切换按钮**：
  - 列表页学费列
  - 移动端卡片学费块
  - 详情页核心信息卡学费块
  都支持单独点击切换；最近一次点击会写入 `localStorage`，并作为当前全站显示偏好。
- 用户选择已持久化：刷新页面后仍保持上次所选显示模式。

## 数据 / 文件变更
- **未破坏原有项目学费字段**：`data/programs.json` 中原始 `tuition.amount` 与 `tuition.currency` 保持不变。
- 新增 fallback 汇率文件：`data/fx_rates_fallback.json`
- 新增前端汇率逻辑：`fx-ui.js`

## 汇率来源
- **实时优先来源**：ExchangeRate-API Open Access
  - Live endpoint: `https://open.er-api.com/v6/latest/USD`
  - 文档页: `https://www.exchangerate-api.com/docs/free`
- 页面会显式展示：
  - 当前使用的汇率来源
  - 获取日期
  - 参考汇率值（如 `1 USD ≈ CNY x.xxx`）
  - 提示文案：**汇率仅供参考，请以最终缴费时实际汇率为准**

## 获取日期
- 本次内置 fallback 快照日期：**2026-05-15**
- 生产环境优先实时请求；请求成功时，页面显示“当前使用实时汇率，获取日期 2026-05-15（或接口返回最新日期）”。

## 回退策略
- 前端加载时先请求实时汇率接口。
- 若实时拉取失败，则回退到 `data/fx_rates_fallback.json`。
- 页面 UI 会明确提示：**使用回退汇率，日期 X**。
- 回退汇率同样保留来源、获取日期与参考说明，不使用无日期的魔术数字。
